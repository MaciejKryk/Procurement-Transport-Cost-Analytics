# Procurement & Transport Cost Analytics Dashboard

## 📊 Project Overview
This Power BI dashboard analyzes procurement and transport costs by comparing Actual vs Budget performance across fiscal years (FY2023–FY2024). 

The objective was to evaluate cost control effectiveness, identify seasonal budget inaccuracies, and provide management-level insights for future financial planning.

---

## 🎯 Key Features
- Budget vs Actual comparison (EUR & % variance)
- Monthly variance breakdown
- Year-to-date (YTD) performance tracking
- Executive KPI summary
- Management recommendation insight

---

## 📈 Key Insights
- Overspend observed in Q2 and December.
- Strong positive variance in Q3 suggests conservative peak-season budgeting assumptions.
- Budget allocation may require recalibration to better reflect seasonal cost dynamics.

---

## 🛠 Technical Implementation
- Power BI
- DAX (Variance calculations, YTD logic, time intelligence)
- Star schema data model
- KPI-driven executive layout

Main DAX logic:
Variance EUR = Budget - Actual  
Variance % = (Budget - Actual) / Budget  

---


## 🚀 Business Value
The dashboard supports data-driven budget optimization by identifying periods of overspend and cost underutilization. It provides decision-ready insights for procurement and transport cost control.
